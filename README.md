# זמני היום בהלכה

אפליקציית ווב (PWA) לחישוב זמני היום ההלכתיים לפי מיקום מדויק, עם בחירה בין שיטות חישוב שונות ואפשרות לשיטה בהתאמה אישית. עובדת במחשב ובמובייל, גם ללא חיבור לאינטרנט.

## הפעלה

זהו אתר סטטי — אין צורך בהתקנה או בשרת מיוחד. אפשרויות:

```bash
npx --yes http-server -p 8123 -c-1 .
```

ואז לגלוש אל `http://localhost:8123`. לחלופין אפשר להעלות את התיקייה לכל אחסון סטטי (GitHub Pages, Netlify, שרת ביתי). לשימוש ב"איתור אוטומטי" (GPS) נדרש HTTPS (או localhost).

**התקנה במובייל:** פותחים את הכתובת בדפדפן הנייד ובוחרים "הוספה למסך הבית" — האפליקציה מותקנת כ-PWA ועובדת גם במצב לא מקוון.

## יכולות

- **מיקום מדויק** — איתור GPS אוטומטי, בחירת עיר ממאגר מובנה, **חיפוש כתובת מדויקת**
  (OpenStreetMap Nominatim; הגובה ואזור הזמן מאותרים אוטומטית דרך Open-Meteo),
  או הזנה ידנית של קואורדינטות וגובה.
- **שיטות מובנות** (לפי המחקר ב-[docs/RESEARCH.md](docs/RESEARCH.md)):
  חזון שמים — מנהג א"י אשכנז (ברירת מחדל), עתים לבינה, לוח ארץ ישראל (הרב
  טוקצינסקי), מנהג הספרדים (הגר"ע יוסף), גר"א דקות שוות, מג"א 72/72.
- **שיטה אישית** — בחירת כלל חישוב לכל זמן בנפרד (מעלות, דקות שוות, דקות
  זמניות, שעות זמניות בבסיס גר"א/מג"א, חצות אסטרונומי/אמצעי). נשמרת במכשיר.
- **שלוש תצוגות** — יומי (עם הדגשת הזמן הבא), **טבלה שבועית** לפי השיטה
  הנבחרת, ו**טבלת השוואה של כל השיטות** ליום הנבחר.
- **חישוב אסטרונומי מדויק** — אלגוריתם NOAA (מאיוס), כולל התאמת גובה
  לזריחה/שקיעה, רפרקציה, וכל אזורי הזמן כולל שעון קיץ. זמני מעלות אינם
  מותאמי-גובה, כמקובל.
- **תאריך עברי באותיות** (ז' באלול תשפ"ו), זיהוי ערבי חג, הדלקת נרות לפי
  מנהג המקום (ירושלים ופ"ת 40 דק', ת"א וב"ב 22, חיפה 30).

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `js/solar.js` | חישובי שמש אסטרונומיים (NOAA/Meeus) — זריחה, שקיעה, זוויות מתחת לאופק, חצות שמש, התאמת גובה |
| `js/engine.js` | מנוע הזמנים — מתרגם "חוקים" (rules) לזמנים בפועל; שעות זמניות גר"א/מג"א |
| `js/methods.js` | הגדרות השיטות (דאטה בלבד) + אפשרויות הבחירה לשיטה אישית |
| `js/cities.js` | מאגר ערים: קואורדינטות, גובה, אזור זמן, מנהג הדלקת נרות |
| `js/hebrew.js` | תאריך עברי ועיצוב זמנים (Intl API מובנה) |
| `js/app.js` | לוגיקת הממשק: מיקום, תאריכים, עורך השיטה האישית, שמירה מקומית |
| `sw.js` | Service Worker — עבודה במצב לא מקוון |

### הוספה או עדכון של שיטה

שיטה היא אובייקט דאטה ב-`js/methods.js`. כל זמן מוגדר על ידי חוק:

```js
{ type: 'degrees',  angle: 16.1, ref: 'sunrise' }   // מעלות מתחת לאופק
{ type: 'fixed',    minutes: -72, ref: 'sunrise' }  // דקות שוות
{ type: 'seasonal', minutes: -72, ref: 'sunrise', basis: 'gra' } // דקות זמניות
{ type: 'shaos',    hours: 3, basis: 'mga' }        // שעות זמניות
```

בעת עדכון גרסה יש להעלות את `CACHE_NAME` ב-`sw.js` (ואת פרמטר `?v=` ב-index.html) כדי שמשתמשים קיימים יקבלו את הקבצים החדשים.

## הבהרה הלכתית

הזמנים מחושבים אסטרונומית ואינם תחליף לפסיקת הלכה. לקביעת הלכה למעשה יש להיוועץ במורה הוראה.
