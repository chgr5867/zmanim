# זמני היום בהלכה

אפליקציית ווב (PWA) לחישוב זמני היום ההלכתיים לפי מיקום מדויק, עם בחירה בין שיטות חישוב שונות ואפשרות לשיטה בהתאמה אישית. עובדת במחשב ובמובייל, גם ללא חיבור לאינטרנט.

## הפעלה

זהו אתר סטטי — אין צורך בהתקנה או בשרת מיוחד. אפשרויות:

```bash
npx --yes http-server -p 8123 -c-1 .
```

ואז לגלוש אל `http://localhost:8123`. לחלופין אפשר להעלות את התיקייה לכל אחסון סטטי (GitHub Pages, Netlify, שרת ביתי). לשימוש ב"איתור אוטומטי" (GPS) נדרש HTTPS (או localhost).

**התקנה במובייל:** פותחים את הכתובת בדפדפן הנייד ובוחרים "הוספה למסך הבית" — האפליקציה מותקנת כ-PWA ועובדת גם במצב לא מקוון (כולל אייקון מותאם ל-iOS ולאנדרואיד).

## יכולות

- **מיקום מדויק** — איתור GPS אוטומטי, בחירת עיר ממאגר מובנה, **חיפוש כתובת מדויקת**
  (OpenStreetMap Nominatim; הגובה ואזור הזמן מאותרים אוטומטית דרך Open-Meteo),
  או הזנה ידנית של קואורדינטות וגובה. אחרי ההגדרה הראשונה כרטיסי המיקום והשיטה
  מתכווצים לשורת סיכום אחת — והזמנים עולים ראשונים במסך.
- **שיטות מובנות** (לפי המחקר ב-[docs/RESEARCH.md](docs/RESEARCH.md)):
  עתים לבינה (ברירת מחדל), חזון שמים — מנהג א"י אשכנז, לוח ארץ ישראל (הרב
  טוקצינסקי), מנהג הספרדים (הגר"ע יוסף), גר"א דקות שוות, מג"א 72/72.
- **שיטה אישית** — בחירת כלל חישוב לכל זמן בנפרד (מעלות, דקות שוות, דקות
  זמניות, שעות זמניות בבסיס גר"א/מג"א, חצות אסטרונומי/אמצעי). נשמרת במכשיר.
- **ארבע תצוגות** — יומי (עם הדגשת הזמן הבא), **טבלה שבועית**, **לוח חודשי
  עברי**, ו**טבלת השוואה של כל השיטות** ליום הנבחר (לחיצה על תא מציגה את דרך
  החישוב).
- **קפיצה לתאריך עברי** — בחירת יום, חודש ושנה עבריים ישירות מהכותרת.
- **שיתוף והדפסה** — כפתור שיתוף (וואטסאפ וכד', או העתקה ללוח) של זמני היום,
  וגיליון הדפסה נקי לתצוגות הטבלאיות (לתליה בבית הכנסת).
- **מצב כהה** — אוטומטי לפי המערכת, עם מתג ידני (אוטומטי/כהה/בהיר).
- **לוח קיר** (`dashboard.html`) — תצוגת שעון LED חיה עם ספירה לאחור לזמן הבא,
  מסך מלא בלחיצה כפולה, ומניעת כיבוי המסך (Wake Lock) לתצוגה רציפה על קיר.
- **חישוב אסטרונומי מדויק** — אלגוריתם NOAA (מאיוס), כולל התאמת גובה
  לזריחה/שקיעה, רפרקציה, וכל אזורי הזמן כולל שעון קיץ. זמני מעלות אינם
  מותאמי-גובה, כמקובל.
- **תאריך עברי באותיות** (ז' באלול תשפ"ו), זיהוי ערבי חג, הדלקת נרות לפי
  מנהג המקום (ירושלים ופ"ת 40 דק', ת"א וב"ב 22, חיפה 30).
- **טיפוגרפיה אחידה** — פונט Heebo מוטמע (עובד גם אופליין), אייקוני SVG
  אחידים בכל מערכות ההפעלה.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `js/solar.js` | חישובי שמש אסטרונומיים (NOAA/Meeus) — זריחה, שקיעה, זוויות מתחת לאופק, חצות שמש, התאמת גובה |
| `js/engine.js` | מנוע הזמנים — מתרגם "חוקים" (rules) לזמנים בפועל; שעות זמניות גר"א/מג"א |
| `js/methods.js` | הגדרות השיטות (דאטה בלבד) + אפשרויות הבחירה לשיטה אישית |
| `js/cities.js` | מאגר ערים: קואורדינטות, גובה, אזור זמן, מנהג הדלקת נרות |
| `js/hebrew.js` | תאריך עברי, המרה עברי↔לועזי ועיצוב זמנים (Intl API מובנה) |
| `js/parasha.js` | פרשת השבוע |
| `js/common.js` | פונקציות תאריכים משותפות לאפליקציה וללוח הקיר |
| `js/app.js` | לוגיקת הממשק: מיקום, תאריכים, תצוגות, שיתוף, עורך השיטה האישית |
| `js/dashboard.js` | לוח הקיר (שעון LED) |
| `sw.js` | Service Worker — עבודה במצב לא מקוון + התראת "גרסה חדשה" |
| `tools/bump-version.mjs` | העלאת גרסת המטמון בכל הקבצים במכה אחת |
| `tools/make-icons.mjs` | יצירת אייקוני ה-PNG מתוך עיצוב האייקון |
| `tests/run-tests.mjs` | בדיקות עוגן למנוע החישוב |

### בדיקות

```bash
node tests/run-tests.mjs
```

שני רבדים: בדיקות סדר הזמנים (עלות < הנץ < חצות < שקיעה < צאת) בכל שיטה
ובכמה מקומות ועונות, ובדיקות רגרסיה מול ~4,000 ערכים קפואים ב-`tests/expected.json`.
אחרי שינוי מכוון בחישוב מריצים `node tests/run-tests.mjs --update` — ובודקים
את ההפרשים מול לוח מודפס לפני שמקבעים.

### הוספה או עדכון של שיטה

שיטה היא אובייקט דאטה ב-`js/methods.js`. כל זמן מוגדר על ידי חוק:

```js
{ type: 'degrees',  angle: 16.1, ref: 'sunrise' }   // מעלות מתחת לאופק
{ type: 'fixed',    minutes: -72, ref: 'sunrise' }  // דקות שוות
{ type: 'seasonal', minutes: -72, ref: 'sunrise', basis: 'gra' } // דקות זמניות
{ type: 'shaos',    hours: 3, basis: 'mga' }        // שעות זמניות
```

### עדכון גרסה

בעת שינוי בקבצים יש להעלות את גרסת המטמון — פקודה אחת שמעדכנת יחד את
`CACHE_NAME` ב-`sw.js` ואת כל פרמטרי `?v=` בקובצי ה-HTML:

```bash
node tools/bump-version.mjs
```

משתמשים קיימים יקבלו פס "גרסה חדשה זמינה — רענון" בטעינה הבאה.

## הבהרה הלכתית

הזמנים מחושבים אסטרונומית ואינם תחליף לפסיקת הלכה. לקביעת הלכה למעשה יש להיוועץ במורה הוראה.
