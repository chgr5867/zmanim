# דו"ח מחקר: שיטות חישוב זמני היום בהלכה

מחקר מקורות שנערך לצורך בניית מחשבון הזמנים. הדוח משמש בסיס להגדרות השיטות
ב-`js/methods.js`. תאריך המחקר: אלול תשפ"ו (אוגוסט 2026).

---

## חלק 1: המחלוקות היסודיות בחישוב זמני היום

### 1.1 הגדרת היום — גר"א מול מגן אברהם (שעות זמניות)

זו המחלוקת המרכזית המשפיעה על סוף זמן ק"ש, תפילה, מנחה ופלג:

| שיטה | הגדרת היום | שעה זמנית |
|---|---|---|
| **הגר"א** (וכן בעל התניא) | מהנץ החמה עד השקיעה | 1/12 מהזמן שבין הנץ לשקיעה |
| **המגן אברהם** | מעלות השחר עד צאת הכוכבים | 1/12 מהזמן שבין עלות לצאת (בזוגות סימטריים: 72/72, 90/90, 120/120, 16.1°/16.1° וכו') |

בזמני הבוקר הגר"א **מאוחר** יותר. בישראל נהוג להציג את שניהם; במחצית השנייה של
היום (מנחה, פלג) רוב המנהג כגר"א בלבד — כך מפורש בהסבר "חזון שמים": "זמני מג"א
שייכים רק בחצי הראשון של היום (ק"ש, שחרית, חמץ); בחצי השני של היום רוב המנהג
כגר"א לגמרי".

### 1.2 עלות השחר וצאת הכוכבים — ד' מיל, ושלוש דרכי מדידה

הבסיס: מעלות השחר עד הנץ = ד' מילין (פסחים צד.). לפי אורך מיל: **18 דק' → 72
דק'; 22.5 דק' → 90 דק'; 24 דק' → 96 דק'**; ושיטת אדמו"ר הזקן (בעל התניא) —
**120 דק'** (עליה עמד הגרא"ח נאה בפולמוס מול הרב טוקצינסקי בתרצ"ט).

שלוש דרכים ליישום השיעור בכל ימות השנה:

1. **דקות קבועות** — אותו מספר דקות כל השנה (מקובל בעיקר בחו"ל האשכנזי).
2. **דקות זמניות** — הדקות מוכפלות ביחס אורך היום (דרך הפוסקים הספרדים בדורנו:
   הגר"ע יוסף, לוח "אור החיים"; המקור בפשטות לשון הרמב"ם).
3. **דקות מתורגמות למעלות** — "השיטה הרווחת בלוחות בא"י": מודדים כמה מעלות
   מתחת לאופק נמצאת השמש 72/90 דק' לפני הנץ בימי ניסן/תשרי בא"י, ומחשבים בכל
   השנה לפי אותה זווית. הערכים המקובלים: **90 דק' = 19.75°** (ויש מחשבים
   19.8°/20°), **72 דק' = 16.013°–16.1°**.

ההצדקה ההלכתית לשיטת המעלות, כלשון בעל "עתים לבינה": בדורות הקודמים קבעו את
הזמנים "על פי ראות העיניים, וזה תואם ללוח שעל פי מעלות ולא ע"פ חישוב אורך
היום"; מייסדי השיטה בלוחות א"י — הרב ידידיה מנת ("זמני ההלכה למעשה") והרב
אברהם יחיאל זילבר ("בירור הלכה").

### 1.3 זריחה ושקיעה — מישורי, גובה, ונראה

ארבע דרגות חישוב (כהגדרת "חזון שמים"):

1. **מישורי** — גובה 0 (פני הים), אופק חופשי. הסטנדרט בלוחות א"י לתחילת/סוף היום.
2. **לפי גובה המקום** — האופק "יורד" ככל שהצופה גבוה (dip); מקדים זריחה ומאחר שקיעה.
3. **נראה (הנץ הנראה)** — בהתחשבות בהרים המסתירים; דורש מודל טופוגרפי (לוחות ביכורי יוסף / Chai Tables).
4. **נראה בניכוי הרים קרובים** — עפ"י פסק מהרי"ל דיסקין (ספר "הנברשת" עמ' נח–נט).

זניט הזריחה/שקיעה הסטנדרטי: **90.8333°** — מרכז השמש 0.833° מתחת לאופק (16′
חצי קוטר + ~34′ רפרקציה). מחלוקת רפרקציה משנית: הרב מנת מדד לא"י **0.5166°
(31′)** — ערך שמאומץ גם ב"עתים לבינה" — לעומת הממוצע הגלובלי 0.566° (34′)
שמשמש את KosherJava.

**כלל אצבע מקובל באפליקציות**: זמנים התלויים בכמות אור (עלות, משיכיר, צאת —
כל זמני המעלות) **לעולם אינם מותאמי־גובה**; רק זריחה/שקיעה עצמן ניתנות
להתאמה (כך Hebcal במפורש, וכך ברירת המחדל של KosherJava).

### 1.4 בין השמשות

- **גאונים/גר"א**: ביה"ש מהשקיעה עד צאת ג' כוכבים בינוניים (¾ מיל = 13.5–18 דק').
- **רבינו תם**: שתי שקיעות; ביה"ש מתחיל 3¼ מיל אחרי השקיעה הנראית (58.5 דק' במיל 18) וצאת בד' מיל = 72 דק'.
- **יראים (ר"א ממיץ)**: ביה"ש מתחיל ¾ מיל **לפני** השקיעה — נפק"מ לחומרא לקבלת שבת.
- **חזון איש**: החמרה במוצ"ש — מנהג בני ברק 40 (ויש 45) דק'.

## חלק 2: שלושת הלוחות הנחקרים

### 2.1 לוח "חזון שמים"

**זיהוי ומחבר**: "חזון שמים" הוא **מפעל הזמנים של הרב איתן צקוני מנתיבות**,
מחבר הספר "חזון שמים" על חכמת התכונה והלכות קידוש החודש לרמב"ם. התוכנה מופצת
ע"י ב.א. פתרונות תזמון בע"מ (sky-view.co.il / skyview2020.co.il), והיא **המנוע
המשמש את רוב הלוחות הדיגיטליים והמודפסים בישראל**. התוכנה מציעה שלושה
מסלולים: מנהג האשכנזים בא"י, מנהג הספרדים ע"פ הגר"ע יוסף, וזמני הרב טוקצינסקי.

### 2.2 לוח ארץ ישראל — הרב יחיאל מיכל טוקצינסקי (הגרימ"ט)

**רקע**: יו"ל מאז תרס"ה (1905); מגבש את "מנהג ירושלים" והוא הבסיס ההיסטורי
לזמנים ה"רשמיים" בישראל. חיבורו התאורטי: "בין השמשות" (ירושלים תרפ"ח).

| זמן | כלל החישוב בלוח |
|---|---|
| עלות השחר | 90 דק' לפני הנץ (ד' מיל × 22.5), מיושם כמעלות — **19.75°** קבוע כל השנה |
| הנץ החמה | מבוסס לוח התצפיות של ביהכ"נ "זהרי חמה" (~תרס"ה); בפועל: נץ אסטרונומי מגובה ההר בניכוי כל ההרים + **תוספת קבועה של 3 דקות** (עיכוב רכס הרי מואב) |
| שקיעה | **אין מנכים הסתרי הרים** ("גם כסוי ההרים... אינו מעלה ואינו מוריד" — בין השמשות עמ' מ') — שקיעה אסטרונומית **מהגובה האמיתי** של הצופה |
| בין השמשות | מהשקיעה עד צאת ג' כוכבים; שיטתו העקרונית כגאונים |
| צאת הכוכבים (חול/מוצאי צום) | ≤31 דק' אחרי שקיעה מישורית בירושלים בשיא הקיץ → **6.45°** (חישוב ה"בירור הלכה" יו"ד רסב). *מחלוקת*: "הזמנים בהלכה" מחשב 6.1°–6.2° |
| מוצאי שבת | מנהג א"י מיסודו — **8.5°** (ג' כוכבים קטנים; ≈36–40 דק') |
| רבינו תם | 72 דק' קבועות |
| מנחה גדולה | בחורף ≈30 דק' אחר חצות (שווה) |
| הדלקת נרות | מנהג ירושלים **40 דק'** לפני השקיעה — המנהג שהלוח קיבע |

*הערת אזהרה* (צקוני, לוחות חי): הטבלאות ההיסטוריות התבססו על חישובי לוח
4־שנתי מלפני ~120 שנה; מומלץ חישוב מחדש ולא העתקת ערכיו.

### 2.3 לוח "עתים לבינה"

**זיהוי**: לוח שנתי פופולרי היו"ל בירושלים ע"י **הרב דוד אהרן סופר**; 17
זמנים יומיים; מהדורות לפי "אופק" של כל עיר ואף לפי כתובת מדויקת; גרסה דיגיטלית
ב-zmanim.online. בסוף הלוח קונטרס "ביאור הזמנים".

| זמן | כלל החישוב |
|---|---|
| שיטה כללית | **מעלות** לכל הזמנים תלויי-האור, כרוב הלוחות בארץ |
| עלות השחר | שני זמנים: עלות א' = 90 דק' במעלות (**19.8°**), עלות ב' = 72 דק' במעלות (**16.1°**) |
| משיכיר | 11.5° (בערים מסוימות — מודיעין עילית, זכרון יעקב — 10.5°) |
| הנץ החמה | שני זמנים: מישורי ונראה. מ~תשפ"ב תוכנת חישוב חדשה לנץ ולשקיעה (כמו לוח "אהבת שלום") — עורר פולמוס |
| שקיעה | **לפי גובה המקום** (התוכנה החדשה אינה מנכה הסתרים מעבר לכ־2000 אמה); שעות הגר"א נשארות על בסיס מישורי |
| בין השמשות דיראים | במעלות עם רפרקציה 0.5166° — 2.1°/2.8°/3.05° מעל האופק |
| צאת הכוכבים (עיקרי) | **"כ־18 דק'"** = ¾ מיל של 24 דק', מיושם במעלות (**≈4.66°**) |
| מוצאי צומות | גלגולים היסטוריים 27→18 דק'; מתשפ"ב "כ־18 דק'" כזמן העיקרי |
| צאת לחומרא | **9.3°** (בניסוח חזון שמים: 9.28° — חזו"א) |
| צאת 6.45° | מובא גם זמן הגרימ"ט ע"פ בירור הלכה |
| רבינו תם | 72 דק' |
| סוזק"ש מג"א | היום מעלות (במעלות) עד צאת המקביל, מחולק לי"ב |
